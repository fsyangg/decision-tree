# tree-race

README generated by Claude.

Decision tree classifiers in C++, benchmarked against scikit-learn's `DecisionTreeClassifier`.

## Implementations

Both trees use Gini impurity and the best split across all features: for each feature the values are sorted and candidate thresholds are the midpoints between neighbouring distinct values. A node becomes a leaf when it has fewer than 5 samples or all its samples share a label.

- **`tree::NodeTree`** (`src/node_tree.h`): recursive, pointer-based. Each node is heap-allocated with `unique_ptr` children, and each split copies its rows into new left/right datasets.
- **`tree::FlatTree`** (`src/flat_tree.h`): nodes live in parallel arrays (`feature_`, `threshold_`, `is_leaf_`) with heap indexing, so the children of node `i` are `2i + 1` and `2i + 2`. Training works on a single array of sample indices that is partitioned in place (Hoare partition) at each split, so the data is never copied. The tree is built iteratively with an explicit stack. A leaf predicts the label of its first sample.

## Build and run

```sh
make build        # conan install + cmake + ninja
make test
make bench-cpp    # ./build/tree_benchmark
make bench-py     # sets up .venv and runs the scikit-learn benchmarks on all datasets
```

To run scikit-learn with the same settings as the C++ trees:

```sh
.venv/bin/python -m pytest bench/pybench -k car_eval --min-samples-split 5
```
